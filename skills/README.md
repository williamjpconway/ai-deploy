# Skills

Mostly empty to begin with. Add a skill once you've done the same multi-step procedure
by hand 2-3 times and the agent keeps tripping on it (see retro.md). `brief-intake/` is
the one standing exception — it's the entry point to every product, not a mistake fix,
so it's written up front instead of earned.

Each skill gets a folder `skills/<name>/SKILL.md` containing: when to use it, the steps,
and how to verify the result.
