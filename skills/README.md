# Skills

Mostly empty to begin with. Add a skill once you've done the same multi-step procedure
by hand 2-3 times and the agent keeps tripping on it (see retro.md). `brief-intake/` and
`new-feature/` are the two standing exceptions — one's the entry point to every product,
the other is how every feature enters the roadmap. Neither is a mistake fix, so both are
written up front instead of earned.

Each skill gets a folder `skills/<name>/SKILL.md` containing: when to use it, the steps,
and how to verify the result.
